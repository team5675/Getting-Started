1. See it

Java calls a function inside a class a method. A parameter names an input; an argument supplies its value in a call. return hands one result back and ends the method call.

public static double meters(double centimeters) {
    return centimeters / 100.0;
}

// Inside main:
System.out.println(meters(75.0)); // prints 0.75

The definition goes inside the class but outside main. The call goes inside main. double before meters says what type comes back. static lets main call this helper without creating an object; objects arrive in Lesson 7. A void method does a job without returning a value. Returning is different from printing: a caller can calculate with a returned number.

2. Try it in Methods.java

First: replace only the TODO return in meters, then run. The first number should become 0.75. The second number is still 0.0 because clamp is unfinished; that is expected at this stage.

Next: finish clamp(value, low, high) using the if statements you learned. These are three inputs: the number to limit, the lowest allowed result, and the highest. If value is below low, return low. If it is above high, return high. Otherwise return value. A return ends that call, so later lines in the method do not run. Assume low is no greater than high. In the real robot · 2027Practice

Source map and exact reviewed versions · Private team repository; excerpts remain readable here.

When the camera reports where the robot is, the code must decide how much to believe it. One small method answers that question. It takes two inputs and returns one number:

Reading example from src/main/java/frc/robot/subsystems/vision/VisionSubsystem.java — do not paste

static double xyStdDevMeters(int tagCount, double avgTagDistM) {
  double stdDev = Constants.Vision.STD_DEV_BASE_M + avgTagDistM * Constants.Vision.STD_DEV_PER_METER;
  if (tagCount >= 2) {
    stdDev *= Constants.Vision.STD_DEV_TWO_TAG_SCALE;
  }
  if (tagCount >= 3) {
    stdDev *= Constants.Vision.STD_DEV_THREE_TAG_SCALE;
  }
  return Math.max(Constants.Vision.STD_DEV_MIN_M, Math.min(Constants.Vision.STD_DEV_MAX_M, stdDev));
}

And the line that calls it — do not paste

double xyStdDev = xyStdDevMeters(obs.tagCount(), obs.avgTagDistM());

This is your clamp idea in a real job. The inputs are how many tags the camera saw and how far away they were. The answer is an “uncertainty” in meters: bigger means trust it less. Far tags make the number bigger, and more tags make it smaller. Math.max and Math.min on the last line keep the answer between a smallest and a largest allowed value. That is exactly what a clamp does. (stdDev *= x is short for stdDev = stdDev * x.)

This method uses its arguments and fixed constants, with no hardware reads, so the team can test it without a robot. static means it belongs to the class and can be called without creating an object; it does not, by itself, make a method independent of hardware or other changing state.
