1. A robot program never finishes

Your Lesson 2–7B programs are standalone main programs: they run from top to bottom once and exit. A robot program is different. It lives in the separate simulation project you open at step 10, and it does not finish by itself: WPILib calls its methods again and again in a loop, 50 times a second, from the moment the robot turns on until it turns off. Each pass reads the controller and sensors, makes decisions and sends new commands to the motors.

Nearly everything you learn in Part 1 runs inside that loop. An if decides what the robot should do right now. A for loop checks every camera. An object, like the battery records in the practice workbook, remembers things from one pass to the next.

A useful habit

When you read unfamiliar robot code, ask three questions. What starts it? Usually a button, a mode change or the loop. What does it change? Usually a field, a motor request or a dashboard value. Where does that change go next? Following one value through the program teaches more than reading a file from top to bottom.

Two ways through

New to programming

Follow the steps in order, starting at Lesson 1; each page’s Next button opens the following step. Repeat a lesson whenever its pause-and-check feels shaky. That isn’t falling behind.

Programmed before

Lesson 1 for setup. In Lessons 2–6, do the short drill first: if it comes easily, skim the worked example and do Part B. Lessons 7, 7A and 7B are new ideas for most people, so read them. From step 10 on, follow every step; the labs build on each other.

2026 tools, 2027 robot

Your lessons use WPILib 2026, the version used in competition through the 2026 season. The team’s practice bot uses a pinned 2027 alpha project for the Pi/SystemCore bench effort. Most ideas are identical. Some names changed: packages start with org.wpilib instead of edu.wpi.first, and the pinned alpha no longer has robotInit(). Both the official stable-2026 template and our simulator already put startup setup in the Robot() constructor. Read the 2027 code for ideas, but type the 2026 versions from the lessons.
