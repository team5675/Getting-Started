Your first success: Hello, World!

Use the Java included with stable WPILib 2026.2.1 to run small programs on your Windows 11 x64 laptop. You need no robot, controller, GitHub account or vendor libraries. Allow one session for installation, then about 20–40 minutes for each topic.

Download the home Java starter

Ten independent exercises, hints, completed answers, and 49 checks. Start with one file. The ZIP is practice material, not the practice robot project.

1. Download and install the tools

  1. Open the official WPILib 2026.2.1 release. Choose its Windows x64 ISO (a large download; allow time and disk space). This is a disc-image file, not a physical disc. This is the released student toolchain for this autumn. The Java concepts carry forward to SystemCore.
  2. In File Explorer, right-click the downloaded .iso and choose Mount. Open the new drive and run WPILibInstaller.exe. If school permissions block installation, ask your mentor or school IT.
  3. Choose Everything and the installation scope your school permits. Include Java and the separate WPILib VS Code. Choose the installer’s option to download VS Code for this computer. Internet is needed: the ISO alone is not a complete offline install. See the official installation walkthrough for the screens; use the pinned release above for the download.
  4. Open the installed WPILib VS Code 2026 shortcut. Keep this guide beside it. Record where WPILib installed its jdk folder.

If WPILib 2026 is already installed for class, keep it. These exercises and the classroom sandbox use the same released tools. We will learn about SystemCore without needing its alpha software. A mentor will announce the move to released 2027 tools after checking the complete library stack. Keep the 2026 project separate; do not accept an alpha importer prompt.

2. Open your own practice folder

  1. Download the starter above. Right-click the ZIP → Extract All. Choose a writable local folder such as C:\dev.
  2. Open the extracted home-java-starter folder. You should see lessons, answers, README.txt, and learning-notes.txt.
  3. In VS Code, choose File → Open Folder and select that folder. Open lessons/HelloWorld.java. Read the TASK comment at the top.
  4. Choose Terminal → New Terminal. Use a PowerShell terminal; it should be in the folder containing lessons. There is no build.gradle in this download. Do not use Create Project, Import Project, Deploy or Simulate for it.

3. Select Java and run Hello World

The JDK contains Java’s compiler and runtime. The command below chooses a particular installed Java. $javaForLessons is a PowerShell variable holding its location; & runs the program at that location. It does not change your computer’s default Java.

PowerShell — replace the quoted path if your installation is elsewhere

$javaForLessons = "C:\Users\Public\wpilib\2026\jdk\bin\java.exe"
& $javaForLessons -version
& $javaForLessons .\lessons\HelloWorld.java

The path shown is the usual all-user 2026 installation. A current-user install can be inside your user folder. Use File Explorer to find the installed jdk\bin\java.exe and copy its path into the quotes. The version command should report 17 for the 2026 install.

Expected output before editing

Hello, World!
TODO
Save your change, then run with check to test it.

System.out.println("Hello, World!"); displays text and ends the line. The main method is where this little program begins. The TODO line comes from the unfinished greeting() method. Replace "TODO" with "Hello, WiredCats!", keep the punctuation, and press Ctrl+S.

Run again, then ask for a check

& $javaForLessons .\lessons\HelloWorld.java
& $javaForLessons .\lessons\HelloWorld.java check

Now the second line is Hello, WiredCats!. The check should say PASS: 1 checks. Explain WHY each result is right. The word check is an argument: extra information passed to the program. This download always runs the selected file’s checks when you supply it.

Recover from a problem
  • “Not recognized” or path not found: locate your actual Java installation. Retype the variable line in each new terminal.
  • Java runs, but cannot find HelloWorld.java: open the folder containing lessons; do not run from inside the ZIP.
  • Compiler error: read the first named file and line. Check quotes, semicolon, and braces. Save before retrying.
  • TRY AGAIN: Java ran successfully, but an answer differs. Read “expected” and “got”; change one thing.
  • A loop never stops: press Ctrl+C. Check that its counter moves toward its stopping condition.
