The same route at home and in class

Start with Lesson 1, then follow Lessons 2–7 using Java foundations. There is one set of instructions and no GitHub account requirement.

One small task at a time

Read the example, predict its output, edit your downloaded file, save and run it. Try a boundary case and write what happened. HelloWorld, Values and Decisions use direct output comparisons. Methods and later files also have supplied checks. Read README.txt in the ZIP for exact PowerShell commands.

After objects, use the simulation starter. It adds real command scheduling, browser inputs, a motion model, logging and PathPlanner. The workbook is optional deeper practice, not another required starting route.

Your first bridge to the team robot

The reviewed 2027 practice code registers a named autonomous message:

NamedCommands.registerCommand(
    "LogMarker",
    Commands.defer(() -> Commands.print("[Auto] LogMarker reached"), Set.of()));

For now, recognize the quoted message. Later lessons explain the factory, scheduler and marker. You can read the example without access to the private repository. Source map and optional team links.
