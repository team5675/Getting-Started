Today’s small goal

Explain where code is edited, where it runs on the robot, and how a sensor reading can change an action. Allow 15 minutes. You do not need a controller or an alpha download.

1. The computer on the robot

SystemCore is the controller that runs the robot program. FIRST says teams will use it in the 2027 FRC season. The laptop is where we write and check code; deployment sends the built program to the controller. The Driver Station lets operators select modes and enable or disable the robot. FIRST’s September 23 announcement.

2. The first lessons still apply

A variable can hold a measured angle. An if statement can reject an old camera reading. A loop can visit four wheels. A method can calculate a speed. An object can remember whether a heading has been checked. Those Java ideas do not belong to one controller model.

For practice, the laptop can run a tiny Java program or a robot simulator. Neither needs a physical roboRIO or SystemCore. We use stable 2026 software now because it makes the first learning steps more predictable; we are preparing to program SystemCore.

3. What changes when the class moves to 2027?

The Java runtime, library packages, project setup and some robot APIs change. For example, the reviewed alpha robot uses org.wpilib imports and performs startup work in its Robot() constructor. The mentor will provide a tested 2027 starter after checking WPILib, vendor libraries and simulation together. Students will open a new, known-working copy and bring over their ideas in small steps. The stable 2026 sandbox stays separate.

The official 2027 changelog is useful to mentors, but is not a beginner’s installation checklist. The final class migration should follow a verified release, not a calendar assumption.

4. Try a sensor-to-action story

Imagine three camera readings: fresh and valid, old, and missing. On paper, write one sentence for each about what your program should do. Compare with the health lesson: it is often better to report why data was rejected than to act on a plausible old number.

Pause and explain

Where do you edit code? Where does the deployed program run? Does installing 2026 tools mean your Java lessons only apply to a roboRIO?

Later: Commands v2 and v3 are two ways to organize actions. Moving to SystemCore does not force a switch to v3.
