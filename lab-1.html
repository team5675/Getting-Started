Simulation Lab 1 of 7

Bind an input to your command

You will prove: press, release and cleanup.

Before you start

Use the sim-starter folder you opened in the robot project step. A fresh download already starts at checkpoint 01, so there is nothing to copy. Keep the simulator, VS Code and the browser station open side by side.

Do this lab in one sitting if you can. Save a backup before you change anything.

Make the edit

Your edit: Open src/main/java/frc/robot/StudentProgram.java. In StudentProgram.configure replace the Lab 1 TODO with this binding. The supplied driver.a() gives you a Trigger: an object that checks whether that input is pressed. Keep the supplied driver/input helpers as they are. Today you only connect this Trigger to the existing light command; writing lambdas is not part of this task.

// A Trigger asks this question repeatedly. whileTrue starts on a press,
// and cancels on release. Our command's end() performs the cleanup.
robot.driver.a().whileTrue(robot.lightCommand());

Run and observe

Start the program, choose Teleop, click the keyboard area and hold Space. The indicator turns on; releasing Space turns it off. Holding the on-screen Light button does the same. Click Disabled while holding it; cleanup still runs. Re-enable with the input released before pressing again.

Try the boundary

Temporarily add .withTimeout(1.0) to the command passed to whileTrue. Hold for two seconds: it finishes after one second and does not restart until you release and press again. Restore the original binding. “While true” describes trigger edges; it is not an endless restart loop.

Connection to the 2027 practice code

The 2027 driver’s A-button brake binding uses whileTrue too. The light owns a light requirement; a drive brake owns the drivetrain requirement. Reviewed source map.

Your turn · Bind another action

Use driver.b().onTrue(Commands.print("B pressed")) to print once per press. Explain how this differs from holding A/Space for the light. B is available in the browser station. Remove this experiment before using B for the mechanism in Lab 7.

Write the behavior you intend before typing. Save your experiment separately from the reference checkpoint.

Save your evidence
