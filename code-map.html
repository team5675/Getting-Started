Three toolchains to recognize

SystemCore does not require learning on alpha software, and Commands v3 is an optional framework choice.

  • Home Java starter: plain Java for the stable WPILib 2026/JDK 17 student route. Also runs with the mentor’s JDK 25. No robot dependencies.
  • Classroom robot sandbox: stable WPILib 2026.2.1 installer; earlier example checks used 2026.2.2 library artifacts, with edu.wpi.first packages.
  • 2027Practice: pinned WPILib 2027.0.0-alpha-7, Phoenix 26.70.0-alpha-2, PathPlannerLib 2027.0.0-alpha-4.1 and AdvantageKit 27.0.0-alpha-6. Its org.wpilib APIs differ. Install/deploy only through the mentor’s matching project instructions.

The architecture reference and older team-project activities also describe a planned baseline. They are not a downloadable, implemented template subsystem in 2027Practice. The 2027 game is unknown; example coordinates and activities here do not predict it.
