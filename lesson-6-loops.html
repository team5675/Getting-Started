Repeat a small task

Repeat a few instructions and follow exactly how many times they run.

Today’s small goal

Trace a short for loop without confusing it with the repeating robot framework.

Before you start: You can read a variable, comparison, and assignment. Keep using the learning sandbox.

Allow 30–45 minutes. This is a planning estimate, not a time limit. Pauses and questions count as learning.

1. Start with repetition you can see

Three separate statements can print three numbers:

Reading example — three separate instructions

System.out.println(1);
System.out.println(2);
System.out.println(3);

A loop repeats a block. We will use a for loop with a small, known range. This is about repetition, not robot movement.

2. Replace the startup method

Where this goes: open src/main/java/frc/robot/Robot.java. Replace only the robotInit() method you added earlier, from its @Override line through that method’s matching closing brace. Keep the rest of the file. Do not add a second robotInit().

Code to use

@Override
public void robotInit() {
    for (int count = 1; count <= 3; count++) {
        System.out.println("Count: " + count);
    }
    System.out.println("Finished counting");
}

There are three parts between the for parentheses, separated by semicolons:

PartWhen it happensMeaning
int count = 1Once, before the first checkCreate a local counter starting at 1.
count <= 3Before each passContinue only while the count is at most 3.
count++After each completed passAdd 1 to count. Here this has the same effect as count = count + 1.

3. Trace the loop on paper

Value at the checkIs it at most 3?What happens
1YesPrint Count: 1, then increase to 2.
2YesPrint Count: 2, then increase to 3.
3YesPrint Count: 3, then increase to 4.
4NoSkip the loop body and continue after it.

Run the new version: save with Ctrl+S, stop the previous simulation, then use Ctrl+Shift+P → WPILib: Simulate Robot Code. Watch the VS Code Terminal. These startup examples run while the simulator is disabled. Need the full steps?

Expected output — read this; do not paste it into Java

Count: 1
Count: 2
Count: 3
Finished counting

The final message is outside the loop body, so it prints once. The loop variable count is local to the loop; do not try to print that name after the loop’s closing brace in this example.

4. Change one part

  1. Change count <= 3 to count < 3.
  2. Predict the last count that will print. Restart and compare.
  3. Restore <=. Change the starting value to 4 while keeping the limit at 3.
  4. Predict whether the body runs at all, then test.
Check your predictions

With count < 3, the body prints counts 1 and 2. Starting at 4 with count <= 3, the first check is already false, so only Finished counting prints.

5. Try a small variation

Print Practice 1 through Practice 4, then print Ready to stop once.

One possible answer

Code to use

@Override
public void robotInit() {
    for (int count = 1; count <= 4; count++) {
        System.out.println("Practice " + count);

6. A loop must be able to finish

If the counter never changes, a condition can stay true forever. That is an infinite loop. Do not deliberately run one for this exercise. If you accidentally do, stop the simulation from its Terminal and check the update part.

Robot code has another kind of repetition: WPILib calls robotPeriodic() repeatedly, normally about every 20 milliseconds. That is about 50 times per second. Each call needs to return so the framework can do other work. Later, check a sensor once per call rather than putting a waiting loop inside that callback.

Pause and check

Explain which part sets the starting value, which part asks whether to continue, and which part changes the value. Say why “Finished counting” prints once.

A good place to stop

Short bounded loops are enough for now. You do not need while loops or complex robot timing to continue. Next session introduces objects: two separate things created from one class.

Save your files. In your learning notes, write one thing you changed, what happened, and one question. Note the lesson number so you can resume here next time.
