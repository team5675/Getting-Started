Show what you can do

You have reached a checkpoint, not the beginning again. Use the completed simulation labs, including the roller you built in Lab 7 and its logs, to demonstrate a small program you understand.

Your capstone mission

  1. Make a backup or Git checkpoint before your change.
  2. Run manual drive, demonstrate slow mode in both directions and release to stop.
  3. Run your autonomous path twice and explain the pose reset and named event.
  4. Inject a stale heartbeat, show the Alert and motion inhibition, then recover deliberately.
  5. Use your own log to explain one result. Name the signals, units, timestamps and what the evidence cannot prove.
  6. Change one behavior, compare the changed lines with your backup (or show a Git diff), and recover the known working version.

Ask a partner to choose an unexpected input or boundary case. Explain what you predict before running it. If something surprises you, use the log to investigate it.

If you skipped the Git step because the training repository was not ready, go back to it with your mentor now to turn one tested change into a reviewed contribution. Sharing to GitHub is a separate milestone from completing this local project.

A useful final explanation

“My input started this command. It required this subsystem. This callback changed the state. This condition ended it. This log signal shows the result.” If you can say that with your own example, you are ready to contribute a small, reviewable robot change.
