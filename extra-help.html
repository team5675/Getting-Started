Lesson 2 · printing and comments

Open Codecademy’s Hello World reference. Read only the sections Print Line and Comments. Focus on what prints and what Java ignores. Skip its compile commands; use ours.

Return to your second message. Can you change the output without changing the comment?

Lesson 3 · values and names

For names, open dev.java’s variables page and jump to Naming Variables. Skip the opening discussion of different field types for now. For types, read the int, double, boolean and String explanations in Primitive Types; do not memorize storage sizes.

For assignment and arithmetic, read just The Simple Assignment Operator and The Arithmetic Operators in Using Operators. Skip its large opening table. Return to your run count and explain what the equals sign does.

Lesson 4 · two choices

In Control Flow Statements, read The If-Then Statement and The If-Then-Else Statement only. Keep braces around our branches even where the reference permits omitting them.

Return to your own decision. Predict the true case and false case before running either one.

Lesson 5 · an input and a result

In Defining Methods, read Defining a Method and Naming a Method. Stop before overloading. For input vocabulary, read the opening parameter-versus-argument explanation in Calling Methods and Constructors; skip the later advanced parameter forms.

Return to your minutes method. Point to the input name, the supplied value and the result.

Lesson 6 · repeat and stop

In Control Flow Statements, jump to The For Statement. Read its start, condition and increment explanation. Stop before the enhanced-for and array example; arrays come later. For while, read the beginning of The While and Do-while Statements, stopping before infinite-loop and do-while examples.

Return to your countdown. Trace the last printed value and one more comparison.

Lesson 7 · separate objects

First reopen our small counter example; it matches your task most closely. For later reading, dev.java’s Classes and Objects index points to individual topics. Choose Creating and Using Objects only when you want more practice with new; leave nested classes and the other topics for later.

Return to resetting one counter. Explain which object changes and which stays the same.
