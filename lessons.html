Find your next small step

Three parts, one small step at a time: first steps in Java, how a robot program runs, and how the robot drives and knows where it is.

Start at home with stable tools

New to programming? Install WPILib 2026 and run Hello World, then download ten small Java exercises with answers and self-checks. This route begins without a robot project. The detailed lessons below explain each concept.

The home exercises and class sandbox use the same stable tools. Learn how this prepares you for SystemCore; alpha packages are optional mentor work.

Choose one lesson at a time

Lessons 1–4 are the first-hours route. Later lessons are for another session, after you can explain a small change from the earlier ones. Each page has its own stopping point. You can reopen any page without losing your place in the code.

Record your current lesson and last working result in learning-notes.txt. The site does not save a progress score or require an account.

See the whole course first: How it all fits together shows the robot program on one page and the two routes through this guide, one for new programmers and one for students who have programmed before.

Practice at home: the practice workbook has extra exercises for each lesson, with self-checks.
