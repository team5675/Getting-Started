Ask now: lambdas, suppliers and method references

Hand over instructions to run later, not a value to keep.

Why this comes now

Labs 4 and 5 give WPILib small pieces of code to call later: robot.drive::getPose, (speeds, feedforwards) -> … and Commands.defer(() -> …). This page explains the -> arrow and the :: double colon.

You will run lessons/LambdaPractice.java from the home-java-starter folder you already have, in a second VS Code window, then return to your robot project.

See it

A lambda is a short unnamed function. () -> controls.value means “read this when asked,” not “remember the number now.” A supplier is an object whose getter provides a value; our DoubleSupplier uses getAsDouble. The long java.util.function name identifies the supplied Java type, not another method you need to write. A method reference such as controls::show names an existing method that can be called later.

public class LambdaPractice {
    static class Controls {
        double value = 1.0;
        void show() { System.out.println(value); }
    }
    public static void main(String[] args) {
        Controls controls = new Controls();
        java.util.function.DoubleSupplier live = () -> controls.value;
        System.out.println(live.getAsDouble()); // 1.0
        controls.value = 2.0;
        System.out.println(live.getAsDouble()); // 2.0
        Runnable display = controls::show;
        display.run(); // 2.0
    }
}
