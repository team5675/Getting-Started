Before you start

Keep working in the same sim-starter folder, with your edits from Lab 2. Lost your work, or starting on a different computer? Stop the simulator and copy checkpoint 03 first; how checkpoints work shows which two files go where.

Do this lab in one sitting if you can. Save a backup before you change anything.

Make the edit

Your edit: After debugging and logs, complete StudentProgram.record with the following named signals. Logger writes values; println is a readable message but is not a substitute for numeric telemetry. These calls run repeatedly, after the model updates.

Logger.recordOutput("Training/InputX", robot.input().x());
Logger.recordOutput("Training/SlowMode", robot.input().slow());
Logger.recordOutput("Training/XMeters", robot.drive.getPose().getX());
Logger.recordOutput("Training/YMeters", robot.drive.getPose().getY());
Logger.recordOutput("Training/HeadingDegrees", robot.drive.getPose().getRotation().getDegrees());
var request = robot.drive.getRequestedSpeeds();
Logger.recordOutput("Training/RequestedSpeedMps", Math.hypot(request.vxMetersPerSecond, request.vyMetersPerSecond));

Run and observe

At home: AdvantageScope. Launch AdvantageScope from the WPILib tools, choose File → Open Log and select the newest .wpilog. Search the sidebar for Training (it may be under RealOutputs). Drag RequestedSpeedMps and AppliedSpeedMps to a Line Graph tab, then add SlowMode. Zoom to your experiment and read timestamps in seconds. This uses the viewer included with WPILib; no separately supplied team file is needed.

Guided session with the locally supplied v11 viewer

In v11, open Topic explorer, search Training/, and click Load topic beside each signal you need. Then choose its A or B graph button. These custom topics are listed at first but loaded on demand; zero retained values before loading does not mean the robot failed to record them.

Record five seconds disabled, normal forward motion, slow forward motion, release, then Disable. Stop Java: click in the Terminal, press Ctrl+C, and type Y if Windows asks “Terminate batch job (Y/N)?”. Find the newest .wpilog under this project’s logs folder. Open it in AdvantageScope, or use v11 when your mentor has supplied its local file. The v11 viewer itself is kept local and is not bundled into this website.

Try the boundary

Select Training/SlowMode, Training/RequestedSpeedMps, Training/AppliedSpeedMps and Training/XMeters. AdvantageKit may show them below RealOutputs. Find the moment slow mode changed using timestamps. Compare displacement over equal time intervals, not an assumed sample count. If a topic is missing, check its exact spelling and whether you restarted the edited program. Label requested and applied values separately; in this ideal model they normally match, but a fault will separate them.

Connection to the 2027 practice code

The real drivetrain records Drive/Pose and Drive/OdometryOnlyPose. Those are two estimates, not ground truth. Your simpler scalar X/Y signals make the first log easier to inspect. Reviewed source map.
