Lesson 1 of 8 · Begin at your own pace

Get comfortable with the tools

Learn what the tools are for before you start changing code.

Today’s small goal

Open a practice project and find the file you will edit. You are not writing a robot program from scratch today.

Before you start: A Windows laptop, internet for installation, and a mentor who can help with permissions or downloads.

Allow 30–60 minutes, plus downloads. This is a planning estimate, not a time limit. Pauses and questions count as learning.

1. Meet the four things you’ll use

A program is a set of instructions a computer can run. We write those instructions in Java, a programming language. We save Java text in files ending in .java.

NameWhat it doesWhat you do with it
VS CodeAn editor: a place to read and change text files.Open a file, type a change, and save.
WPILibTools and code provided for FRC robot programming.Use its project creator, build command, and simulator.
Build / compilerChecks Java and turns source code into a runnable form.Read whether the build succeeded; fix a reported error if it did not.
SimulatorRuns the robot program on your laptop.Try beginner examples without a physical robot.

A project is a folder containing your code and its setup files. Opening that folder lets the tools work together. You will use a template: a project with the framework code already in place. Think of it as starting with a labeled notebook instead of loose pages.

2. Install the team’s tools

If a mentor already installed WPILib 2026, skip to step 3 below. Installation can take longer than a lesson; that does not mean you are behind.

  1. Ask your mentor which stable WPILib 2026 version the class uses. These instructions follow the 2026.2.1 template. Use the official installer or the specific 2026 release they provide.
  2. Follow the installer’s Java/tools setup. Include the WPILib copy of VS Code. If it offers to download VS Code, let it obtain that copy.
  3. When setup is complete, open WPILib VS Code 2026 from the Windows Start menu. Keep the guide open beside it.
  4. Hold Ctrl and Shift, tap P, then release the keys. This opens the Command Palette, a search box for editor actions. Type WPILib.
  5. Look for commands such as WPILib: Create a new project. Press Esc to close the palette.
I cannot find the WPILib commands

Check the editor you opened: a regular VS Code window may not have the FRC tools. Close the palette and open the 2026 WPILib shortcut. If commands are still absent, ask a mentor to check installation. Do not switch to a 2027 alpha install to get past the problem.

The team also has experimental SystemCore work. It uses separate tools; it is not part of these first lessons.

3. Create a practice project

  1. In File Explorer, create a folder such as C:\dev if it does not exist. If your school laptop prevents that, ask a mentor for a writable local folder outside OneDrive.
  2. In WPILib VS Code, open the Command Palette again. Choose WPILib: Create a new project.
  3. Choose Template, language Java, and template Command Robot. These lessons use that template, even though we will leave commands until later.
  4. Choose C:\dev as the base folder, enter learning-sandbox as the project name, and enter team number 5675. Let the creator make the named project folder. If there is a desktop-support option, enable it for simulation.
  5. Generate the project and open it when prompted. The folder you open should contain build.gradle and src. Do not open only the Java file.
  6. If a trust prompt appears for the folder you just generated, confirm with your mentor that this is your new local project, then trust it. Wait for the editor to finish loading the Java project.

If your mentor gave you an already-prepared learning sandbox, use File → Open Folder to open its project folder instead. Do not overwrite someone else’s project.

4. Find your way around the editor

  1. Choose the Explorer icon on the left (overlapping file shapes). Open the folders src → main → java → frc → robot. Some may appear combined as one row.
  2. Click Robot.java. Look for its filename on the editor tab.
  3. Try the shortcut Ctrl+P, type Robot.java, and press Enter. This finds a file; Ctrl+Shift+P finds an action.
  4. Choose Terminal → New Terminal to see the bottom panel. You do not need to type a terminal command now.

5. Keep a short learning note

In the Explorer, select the project’s top folder and use New File to create learning-notes.txt. This is plain text, not Java. Write your project’s location and “Next: Lesson 2.” Press Ctrl+S to save.

Saving writes your edit to disk. It does not run the program. When you return another day, open the same project folder and your notes.

Pause and check

Without a partner pointing, find Robot.java, the Command Palette, and the Terminal panel. Explain which one you would use to edit a message and which one you would use to read the result.

A good place to stop

You have a place to practice. If installation or opening the project is still failing, stop here and get help with that setup; the next lesson depends on it. You do not need to learn the rest of the folder tree yet.

Save your files. In your learning notes, write one thing you changed, what happened, and one question. Note the lesson number so you can resume here next time.
