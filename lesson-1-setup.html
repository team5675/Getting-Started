Make a place to practice

One folder and one working Java installation.

One setup for class and home

Install the stable tools, extract one folder, and find the file you will run. No robot or GitHub account is required.

TEAM TIP

Start with one working program.

You do not need to understand the whole robot today. Get the tools ready, then let one small success lead to the next.

New to files, folders and programming tools? Start here.
File and folder
A file is one saved item, such as HelloWorld.java. A folder groups files. A path, such as lessons/HelloWorld.java, tells you which folder to look inside.
ZIP and Extract All
A ZIP packs several files into one download. Extract All makes normal folders you can edit. Downloading alone does not extract them.
Editor and Terminal
Type Java instructions in the editor. Type the lesson’s run commands in the PowerShell Terminal below it. The Terminal also shows output and errors.
Save and run
Ctrl+S saves your edit to the file. Running asks Java to execute the saved instructions. An unsaved edit will not appear in the result.

You can learn these skills here. Ask for setup help if a step looks different; installing tools is not a test of your programming ability.

1. Install the class tools

Use WPILib 2026.2.1 for Windows x64. The ISO is the installer disc image: Windows can open it without a physical disc. Download the ISO, open it in File Explorer, and run WPILibInstaller.exe. Select the Java/tools installation and include WPILib VS Code; let the installer obtain VS Code if offered. If a mentor already installed these tools, use that installation.

Open WPILib VS Code 2026 from Start. The team’s experimental SystemCore tools belong to a different project; stay with 2026 here. Installation can take longer than a lesson.

2. Extract your practice folder

  1. Download Java foundations.
  2. In File Explorer choose Extract All, to a writable local folder such as C:\dev. Open the extracted home-java-starter folder, not the ZIP preview.
  3. In VS Code choose File → Open Folder and select that folder. In Explorer you should see lessons, answers and README.txt.
  4. Press Ctrl+P, type lessons/HelloWorld.java, and press Enter. Ctrl+P finds a file; Ctrl+Shift+P finds an editor action.

3. Select the installed Java

Choose Terminal → New Terminal. Use PowerShell. Click after its prompt (often beginning with PS). Enter each line below, pressing Enter after each one. Copy only the command, not the prompt. These lines go in the Terminal, not HelloWorld.java. For an all-users installation, enter:

$javaForLessons = 'C:\Users\Public\wpilib\2026\jdk\bin\java.exe'
& $javaForLessons -version

Look for Java 17. For a current-user installation, find the 2026 folder under your own user folder and use its jdk/bin/java.exe instead. The variable remembers the path in this terminal. The & tells PowerShell to run that program. Set it again when you open a new terminal.

The path does not exist, or a different Java version appears

Use File Explorer to locate the Java installed with stable WPILib 2026. Copy its full path, including java.exe, between the quotes. Ask a mentor if the installation is missing. Do not install an alpha to fix this.

4. Save a learning note

In VS Code press Ctrl+P and open learning-notes.txt. Record your folder location and “Next: Lesson 2.” Save with Ctrl+S.

Ready?

Find HelloWorld.java, the Terminal and your Java version. Lesson 2 will run the program. There is no robot project to create yet.
