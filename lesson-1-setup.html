Lesson 1 · Java foundations

Make a place to practice

One folder and one working Java installation.

One setup for class and home

Install the stable tools, extract one folder, and find the file you will run. No robot or GitHub account is required.

TEAM TIP

Start with one working program.

You do not need to understand the whole robot today. Get the tools ready, then let one small success lead to the next.

New to files, folders and programming tools? Start here.
File and folder
A file is one saved item, such as HelloWorld.java. A folder groups files. A path, such as lessons/HelloWorld.java, tells you which folder to look inside.
ZIP and Extract All
A ZIP packs several files into one download. Extract All makes normal folders you can edit. Downloading alone does not extract them.
Editor and Terminal
Type Java instructions in the editor. Type the lesson’s run commands in the PowerShell Terminal below it. The Terminal also shows output and errors.
Save and run
Ctrl+S saves your edit to the file. Running asks Java to execute the saved instructions. An unsaved edit will not appear in the result.

You can learn these skills here. Ask for setup help if a step looks different; installing tools is not a test of your programming ability.

1. Install the class tools

You need WPILib 2026. One installer gives you VS Code, Java 17 and the robot tools. Plan for 30–60 minutes; most of it is download time. If a mentor already installed WPILib 2026 on this computer, skip to step 2.

  1. Open the WPILib 2026.2.1 release page. Under Assets, download the file whose name starts with WPILib_Windows and ends in .iso. It is over 2 GB. (An ISO is a disc image: Windows opens it without a physical disc.)
  2. In File Explorer, right-click the downloaded .iso file and choose Mount. It opens like a disc.
  3. Double-click WPILibInstaller.exe. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  4. Click Start. Choose Everything, then click Install for this User, which needs no administrator password. On the next page click Download for this computer only. When it says “Done Downloading. Press Next to continue”, click Next. Wait for WPILib to finish installing, then click Finish.
  5. Open 2026 WPILib VS Code from the desktop or the Start menu. Use this one, not another copy of VS Code. The team’s experimental 2027 tools belong to a different project; stay with 2026 here.

Whichever option you choose, WPILib 2026 puts its files, including Java 17, in C:\Users\Public\wpilib\2026. The lesson folder finds that Java for you.

2. Extract your practice folder

  1. Download Java foundations.
  2. In File Explorer, right-click the ZIP and choose Extract All. In the box that asks where to put the files, replace the suggested path with C:\dev and click Extract. You now have C:\dev\home-java-starter. (If you keep the suggested path, you get a folder inside a folder with the same name. That still works: open the inner one.)
  3. In 2026 WPILib VS Code choose File → Open Folder, pick C:\dev\home-java-starter and click Select Folder. If VS Code asks whether you trust the authors, choose Yes, I trust the authors: this is the team’s download. In the Explorer panel you should see lessons, answers, run.cmd and README.txt.
  4. Press Ctrl+P, type lessons/HelloWorld.java, and press Enter. Ctrl+P finds a file; Ctrl+Shift+P finds an editor action.

3. Check that Java is ready

Choose Terminal → New Terminal. A panel opens at the bottom with a prompt that ends in home-java-starter>. Click after the prompt, type this and press Enter. It goes in the Terminal, not in HelloWorld.java:

.\run

Expected output

Java 17 from WPILib 2026 is ready.
Run a lesson file like this:  .\run HelloWorld

.\run means “the run file in this folder”. It finds the Java 17 that WPILib installed, so you never need to type where Java lives. From Lesson 2 on you type .\run followed by a lesson file’s name.

Something else appeared
The term '.\run' is not recognized
Look in the Explorer panel first. If you see lessons but no run.cmd, your folder came from an earlier download: add the launcher to an older folder. Otherwise the Terminal is in a different folder. Check that the prompt ends in home-java-starter>. If not, use File → Open Folder on C:\dev\home-java-starter again and open a new Terminal.
Could not find the Java that WPILib 2026 installs.
WPILib 2026 is not installed yet, or its install did not finish. Go back to step 1, or ask a mentor. Do not install a different Java or an alpha version to fix this.
… is not Java 17.
The WPILib 2026 folder holds a different Java than expected. Ask a mentor.

4. Save a learning note

In VS Code press Ctrl+P and open learning-notes.txt. Record your folder location and “Next: Lesson 2.” Save with Ctrl+S.

Ready?

Find HelloWorld.java and the Terminal, and see the “Java 17 from WPILib 2026 is ready.” message. Lesson 2 will run the program. There is no robot project to create yet.
