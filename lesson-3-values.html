1. A variable gives a value a name

Imagine tracking how many practice runs you have completed. You could print a sentence with a number already written into it. A variable gives the number a name, so code can use and change it. We’ll call ours practiceRuns.

Where this goes: open src/main/java/frc/robot/Robot.java. Replace only the robotInit() method you added earlier, from its @Override line through that method’s matching closing brace. Keep the rest of the file. Do not add a second robotInit().

Code to use

@Override
public void robotInit() {
    int practiceRuns = 3;
    System.out.println(practiceRuns);
}

Read the first line from left to right:

PieceMeaning
intThe type: this variable stores a whole number.
practiceRunsThe name we chose. Type this exact spelling whenever you use it.
= 3Put the value 3 into the variable. Here = means assignment, not a math question.
;End the statement.

The print line has no quotes around practiceRuns, so Java looks up the variable’s value. Try changing only 3 to 7. Save, restart simulation, and check that 7 prints.

3. Change the stored value

Replace the method with the version below. // begins a comment: a note for people that Java does not execute.

Code to use

@Override
public void robotInit() {
    int practiceRuns = 3;
    practiceRuns = practiceRuns + 1; // Read the old value, add one, store the result.
    System.out.println("Runs: " + practiceRuns);
}
  1. At the declaration, the stored value is 3.
  2. On the next line, Java evaluates the right side: 3 + 1 gives 4.
  3. Assignment stores 4 under the same name. It replaces the previous value.
  4. The print statement reads 4.

Expected output — read this; do not paste it into Java

Runs: 4

Use int when you first declare the variable. Do not write int again when changing that same variable in this method. Each new program run starts this method again, so this example begins at 3 every time; it is not a permanent record of your runs.

4. Meet three more types

Different values need different types. Replace your method with this example and inspect the output.

Code to use

@Override
public void robotInit() {
    int practiceRuns = 3;
    double distanceMeters = 1.5;
    boolean ready = true;
    String teamName = "WiredCats";

    System.out.println("Team: " + teamName);
    System.out.println("Runs: " + practiceRuns);
    System.out.println("Distance: " + distanceMeters);
    System.out.println("Ready: " + ready);
}

Run the new version: save with Ctrl+S, stop the previous simulation, then use Ctrl+Shift+P → WPILib: Simulate Robot Code. Watch the VS Code Terminal. These startup examples run while the simulator is disabled. Need the full steps?

Expected output — read this; do not paste it into Java

Team: WiredCats
Runs: 3
Distance: 1.5
Ready: true
  • double stores a number that can have a fractional part. Use a decimal point, not a comma.
  • boolean stores true or false. Those values do not have quotes.
  • String stores text. Its type name begins with a capital S.

Units are our responsibility. distanceMeters tells a person that 1.5 means meters. Java sees a number; it does not infer meters from the name.

5. Your turn, with a hint if needed

Replace only the contents of your method to store a whole number called startingCount with value 4, add 2 to it, and print Count: 6.

Hint: three statements

First declare the variable with int. Then assign startingCount + 2 back to the same name. Finally print a quoted label joined to the variable.

One possible answer

Code to use

@Override
public void robotInit() {
    int startingCount = 4;
    startingCount = startingCount + 2;
    System.out.println("Count: " + startingCount);
}

Change the starting value to 8. Before running, predict the new result. That small variation checks your understanding.

Common problems

  • Cannot find symbol: check spelling and capitalization. A local variable must be declared before you use it, inside the block where it is available.
  • Variable already defined: you may have pasted a second declaration into the same method. Replace the earlier example instead of stacking every example together.
  • A decimal will not fit in int: use double when the value needs a fractional part.
Pause and check

Explain the difference between "practiceRuns" and practiceRuns. Trace the value before and after an assignment. Change one value and predict its output.
